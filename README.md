# Ultrakey Invoice Management System

A full-stack web application for managing invoices, quotations, clients, payments, taxes, and business settings.

## 🚀 Project Overview

The Ultrakey Invoice Management System is a web-based application designed to simplify quotation and invoice management for businesses.

The application provides a modern frontend built with React and a REST API backend built with Django REST Framework.

## ✨ Features

- User Registration and Login
- Protected Application Routes
- Dashboard
- Client Management
- Invoice Management
- Quotation Management
- Invoice Item Management
- Quotation Item Management
- Business Settings
- General Settings
- Payment Settings
- Tax Settings
- Email Settings
- PDF Settings
- Translation Settings
- Invoice PDF Generation
- Authentication using Token Authentication
